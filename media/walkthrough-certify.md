# 3 · Visualize, certify & protect

- [📊 Open the Sequence Visualizer](command:biolint.showSequenceView) — ORF map, restriction sites, GC profile. Click any ORF to jump to it in the editor.
- [🛡️ Export a compliance certificate](command:biolint.exportCertificate) — SHA-256 snapshot with per-record GC + biosafety verdict.
- [⛔ Install the pre-commit hook](command:biolint.installPreCommitHook) — blocks commits containing `REJECTED` patterns, even offline.
- [🎨 Continue in SynthFlow Studio](command:biolint.openSynthFlowStudio) — bridge to visual design.
